## How to Use `timberborn_bundle_extractor.py`

### Basic Usage (Extract Blueprints & Timbermeshes)
```bash
python timberborn_bundle_extractor.py "C:\Program Files (x86)\Steam\steamapps\workshop\content\1062090\3346318229\version-1.1\AssetBundles\emberpelts_win"
```

### Specify Output Directory & Custom Manifest
```bash
python timberborn_bundle_extractor.py "C:\...\emberpelts_win" --manifest "C:\...\emberpelts_win.manifest" --output "D:\Timberborn Mod development\Extracted_Output"
```

## Output Structure Generated by Extractor

When run against an AssetBundle (e.g. `emberpelts_win`), the utility produces:

```text
Extracted_Output/
├── Blueprints/               # All raw extracted blueprint .json files (e.g. Floodgate.Flat.1x1.Emberpelts.blueprint.json)
├── Timbermeshes/             # All extracted 3D model .timbermesh files
└── Structured/               # Exact directory tree reconstructed using the .manifest file:
    └── Resources/
        ├── Buildings/
        │   ├── Housing/
        │   ├── Landscaping/
        │   └── Water/
        ├── Recipes/
        └── Factions/
```

## Key Features & Solved Problems

1. **Automation Rule System & Localization Resolver**: Standardized threshold evaluation (`10%` input, `90%` output, `75%` excess sawdust) and auto-mapped English localizations for mod and base game recipes.
2. **Unity 6 / Timberborn 1.1 Support**: Fixes `struct.error: iterative unpacking requires a buffer of a multiple of 32 bytes` thrown by standard `UnityPy` when reading modern TypeTrees.
3. **Auto Manifest Hierarchy Matching**: Automatically parses matching `.manifest` files and reconstructs the game asset directory tree (`Resources/Buildings/...`).
4. **Timbermesh 3D Extraction**: Locates zlib binary payload streams embedded inside MonoBehaviours and extracts valid `.timbermesh` files.
